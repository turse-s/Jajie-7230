该版本与之前版本比主要DEBUG项目如下
- [x] 俯仰翻转后俯仰返回值不回传了，水平返回值正常
- [x] debug时出现异常退出的问题
- [x] 水平定位bug，水平执行goto指令，会翻转180°，goto0去了180°
- [x] 水平在定位工程中出现过冲问题
- [x] 俯仰在机械原点与用户原点不同的时候，goto坐标会出现镜像翻转
- [x] 预置位设置bug：16,112预置位无法设置，取消激光灯控制预置位
- [x] 翻转坐标系bug：翻转坐标系后goto指令与返回坐标不符
- [x] 将云台的俯仰限位角度由45~290改为60~275，云台在未设置俯仰限位时仍然使用45~290的默认角度以便于大量出货的状态，在接收到角度设定命令后可以设置为60~275
- [x] 云台在设置守望位后，如果设置230则坐标会变为原点，这是有问题的。应该的动作是设置230不影响守望位，调用230会删除守望位。

- [x] 守望位设置为设置守望位，守望位删除为关闭守望位，守望位调用为开启守望位，守望位功能与2515相同
- [x] 手控俯仰运行过程中会被守望位打断
- [x] 229巡检105，111,114,116预置位会跳过，需要修改程序如下位置
- [x] 观察程序如下位置并进行分析，为什么会出现两个预置位调用，该位置的预置位调用限制也需要调整
- [x] 增加CDS光敏控制
- [x] 关闭不停的请求ZOOM值得情况
- [x] 更新固件版本号为0202
同时该版本将激光灯的控制进行了条件编译，由于激光灯光敏与编码器共用IO所以通过条件编译可以释放该IO。该版本还对变量进行了优化是的编译的警告项目为0。
